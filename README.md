## 🛠️ Local Development

To run the site locally:

1. Clone this repository:
   ```bash
   git clone https://github.com/adityadhimaann/devfolio.git
   cd devfolio
   ```

2. Start a local HTTP server:
   ```bash
   # Using Python 3
   python3 -m http.server 5500

   # Or using Node.js
   npx serve .
   ```

3. Open your browser and navigate to:
   ```text
   http://localhost:5500/
   ```
